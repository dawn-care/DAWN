# Metrics

Generated by [`.github/workflows/pr-metrics.yml`](https://github.com/dawn-care/DAWN/blob/canary/.github/workflows/pr-metrics.yml)
on a nightly schedule (and on manual `workflow_dispatch`). Each run
recomputes every file here from the full PR history and overwrites
it - nothing is appended or merged with the previous run.

## `reviewers.json`

Per-person count of merged PRs reviewed.

```json
{
  "generatedAt": "2026-11-05T05:00:00Z",
  "windowDays": 14,
  "allTime": { "<login>": <count> },
  "trailingWindow": { "<login>": <count> }
}
```

- `generatedAt`: when this run produced the file (UTC).
- `windowDays`: the width of `trailingWindow`, in days, so a reader doesn't have to hardcode it.
- `allTime` / `trailingWindow`: GitHub login to number of merged PRs that person left at least one review on, either ever (`allTime`) or within the last `windowDays` days of `generatedAt` (`trailingWindow`). A PR reviewed more than once by the same person still counts once.
- Excluded from both: bot reviewers (GitHub `Bot` accounts, e.g. Copilot's reviewer), and a PR author's own review of their own PR. Both happen in this repo's history and aren't review-load signal.
